Describing the dataset used, why it was chosen, and the cleaning steps performed.

Dataset Description

What the Dataset Contains

The dataset is titled "Mental Health and Lifestyle Habits (2019–2024)" by Atharva Soundankar, available on Kaggle. It contains survey-style data collected from 3,000 individuals across multiple countries and years. The dataset includes the following 12 columns:

ColumnDescriptionType
CountryParticipant's country of residenceText
AgeParticipant's age in yearsNumeric
GenderMale / Female / OtherText
Exercise LevelLow / Moderate / HighText
Diet TypeBalanced / Vegan / Vegetarian / Keto / Junk FoodText
Sleep HoursAverage nightly sleep in hoursNumeric
Stress LevelLow / Moderate / HighText
Mental Health ConditionNone / Anxiety / Depression / Bipolar / PTSDText
Work Hours per WeekAverage weekly work hoursNumeric
Screen Time per Day (Hours)Daily screen time in hoursNumeric
Social Interaction ScoreSelf-rated social interaction (0-10)Numeric
Happiness ScoreSelf-rated happiness (0-10)Numeric

Why This Data Was Chosen

This dataset was chosen because it directly contains both sleep-related variables (Sleep Hours) and mental health outcome variables (Happiness Score, Mental Health Condition) in the same dataset, making it ideal for my analysis. It is well-structured, publicly available, covers a multi-year period (2019–2024), and includes a large sample of 3,000 participants across 7 countries, adding credibility to the findings.

Cleaning Code & Explanation

How the Cleaning Worked

Step 1

Remove duplicates - drop_duplicates() checks every row and removes any exact copies, preventing the same data point from being counted twice and skewing results.

Step 2

Drop missing values - dropna() removes rows where any of the four most important columns are empty. This reduced the dataset from 3,000 to 2,405 rows.

Step 3

Standardise text - .str.lower().str.strip() converts all text to lowercase and removes extra spaces, so "Male" and " male" are treated as the same value.

Step 4

Rename columns - .str.replace(' ', '_') removes spaces from column headers, making them easier to reference in Python code.

Step 5

Remove out-of-range values - filters out any rows where sleep hours fall outside 0-24 or happiness scores fall outside 0–10, removing clearly erroneous data entries.
